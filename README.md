# Power BI DAX Sales Dashboard

## About This Project
I created this dashboard to practice DAX functions in Power BI and learn more about working with sales data.

## Tools Used
- Power BI
- DAX
- Excel

## What I Did
- Imported sales data from Excel.
- Created calculated columns and measures.
- Used SUM, AVERAGE, MIN, MAX, and DIVIDE.
- Practiced IF, AND, OR, and SWITCH.
- Created 5 KPI cards and 4 charts.

## What I Learned
I learned how to use DAX formulas to calculate sales, work with data, and create charts that make the results easier to understand.
